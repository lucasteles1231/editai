# Baixar o Editai

Grátis, de código aberto e sem conta: o Editai roda no seu computador, e o vídeo não vai
para servidor nenhum.

<Baixar />

## O que o computador precisa

- **Sistema:** macOS, Windows 10 ou 11, ou Linux.
- **Disco:** uns 0,8 GB para o editor e o modelo de transcrição. A [Minha voz](./guia/minha-voz),
  opcional, pede mais uns 3,5 GB.
- **Memória:** 8 GB bastam para editar. O detalhe de cada função está em
  [O que cada função precisa](./guia/o-que-cada-funcao-precisa).
- **Internet:** só para instalar e no primeiro uso de cada modelo. Depois, o Editai funciona
  sem ela.

## Depois de instalar

- **Abrir:** pelo atalho **Editai**, ou com `editai` num terminal. Veja o
  [Começo rápido](./guia/comeco-rapido).
- **Atualizar:** o Editai avisa quando sai uma versão nova. Veja [Atualizar](./guia/instalacao-em-detalhe#atualizar).
- **Desinstalar:** `editai --desinstalar`. Veja [Desinstalar](./guia/instalacao-em-detalhe#desinstalar).
- **As versões anteriores** estão na [página de versões do GitHub](https://github.com/lucasteles1231/editai/releases),
  e o que mudou em cada uma, em [Versões](./versoes).
